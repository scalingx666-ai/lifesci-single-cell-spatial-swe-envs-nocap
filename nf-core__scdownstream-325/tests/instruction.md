# Issue

**Title:** Require unique sample names in the samplesheet

## Description

Reject samplesheets with duplicate sample names.

Downstream steps key on `meta.id`, which comes from the `sample` column, so duplicate names lead to clashing outputs. `assets/schema_input.json` now sets `"uniqueEntries": ["sample"]`, and nf-schema fails input validation on duplicates. `docs/usage.md` states the requirement.

Local checks: `nf-core pipelines lint` shows only the three `files_unchanged` logo failures that also exist on `dev`. `tests/default.nf.test` and the first two other pipeline tests pass with Apptainer; CI covers the rest.
